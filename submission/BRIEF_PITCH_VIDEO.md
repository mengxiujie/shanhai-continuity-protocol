## Spoken script (~145 words)

I'm an independent builder working on Shanhai Continuity Protocol.

AI agents can pass information to one another in seconds. What they often cannot answer is a simpler question: *is this still the version the person approved, for this recipient and this purpose?*

Imagine an organizer approves an event brief for Friday. The date changes to Saturday. An agent already holding Friday's permission should not quietly carry that permission over to the correction. And private planning notes should not travel with the approved brief.

We built a narrow handoff prototype on Monad Testnet. The content stays encrypted off-chain. Monad records the minimum grant state. A separate receiving process checks the current version before it decrypts. In our fixed fictional test, Friday worked; the obsolete request stopped; Saturday worked only after a new approval; and revocation stopped the next request.

This is not a claim of real-user adoption or live model intelligence. We are building it because useful AI continuity should not require people to surrender control of what follows them.
