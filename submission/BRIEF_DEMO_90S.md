## Narration

You ask an outside AI assistant to write an event announcement.
You approve Friday at seven. Then the event moves to Saturday at three.
Which version is the next assistant allowed to receive?

Shanhai makes that decision explicit.
The client approves one brief, not the entire conversation.
Private planning notes and an unapproved suggestion stay outside this handoff.

The brief is encrypted off-chain.
Monad records the version, recipient and authorization.
Before delivery, the sender checks that record.
An independent recipient process checks again before decrypting.

First, the approved Friday brief arrives.
In this demonstration, its verified fields fill a fixed announcement template. No live model is used.

Now the client changes the date.
The old request is rejected before a new delivery.
Publishing a correction does not grant access to it.

The client separately approves version two.
The recipient receives Saturday at three, and the announcement updates.

Finally, the client revokes that authorization.
The next request is denied. Previously received plaintext cannot be recalled.

The source, scope and version travel with the brief.
The next handoff follows the client's current approval.
