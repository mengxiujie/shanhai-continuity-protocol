# Public repository boundary

## Included

- SCP specification, schema, conformance vectors, and reference implementation.
- Synthetic Owner/Agent B browser demo.
- ConsentRegistry source, ABI artifact, verifier, and deployment instructions.
- Evidence-level documentation and hackathon disclosures.

## Excluded

- Real user conversations, memories, voice, identity data, or payment records.
- Internal product strategy, pricing research, market interviews, governance ledgers, and private operating documents.
- Production prompts, production infrastructure configuration, credentials, cookies, wallet material, or analytics exports.
- Portal screenshots and raw organizer/support conversations that can contain account information.

## Design reason

The submission demonstrates the interoperable authorization and continuity primitive. It does not require publishing every layer of the commercial product. If formal event rules later require a broader code boundary, the owner must obtain a written organizer answer before expanding this repository.
