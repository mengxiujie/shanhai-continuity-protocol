# AI tool usage disclosure

OpenAI Codex and other AI-assisted tools were used for research support, specification organization, code generation, review, and test scaffolding.

The project owner remains responsible for:

- the product thesis and scope;
- authorization and user-rights decisions;
- accepting, rejecting, or correcting generated work;
- executing identity-, passkey-, wallet-, and submission-related actions;
- verifying all evidence and making the final hackathon submission.

AI-generated text or code is never treated as proof by itself. Claims in this repository are tied to executable tests, artifacts, portal records, or explicitly marked limitations.

OpenAI Codex assisted with the connected Owner/Agent B runtime, signed-request identity checks, deterministic test fixtures, local wallet workbench, dependency remediation, public documentation research and judge-facing text. Parallel Codex agents worked on scoped implementation and review tasks in the shared repository; the resulting changes were checked through actual local suites and build/release checks.

The sprint implementation connects authorization checks with actual encrypted delivery and independent-process context construction. Passing controlled tests for that implementation is still not evidence that a real Monad deployment or wallet transaction occurred.

The model gateway used in this submission is a deterministic simulation, with no external model calls. AI assistance during development must not be confused with a live model handling the demonstrated synthetic context. This work does not validate model behavior, natural-language understanding or consumer value.

Codex may prepare reproducible commands, unsigned transaction requests and public evidence summaries. Wallet signatures and final submission remain owner-controlled. At this checkpoint no dedicated test wallet, real signed deployment/state-transition sequence or public final submission has been completed. No private key, seed phrase, participant material or proprietary prompt corpus is included in this public candidate.

Mera remains outside the primary sprint. AI-written descriptions, simulated receipts and started local servers cannot establish sponsor-bounty completion or production security.
