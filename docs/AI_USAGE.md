# AI tool usage disclosure

OpenAI Codex and other AI-assisted tools were used for research support, specification organization, code generation, review, and test scaffolding.

The project owner remains responsible for:

- the product thesis and scope;
- authorization and user-rights decisions;
- accepting, rejecting, or correcting generated work;
- executing identity-, passkey-, wallet-, and submission-related actions;
- verifying all evidence and making the final hackathon submission.

AI-generated text or code is never treated as proof by itself. Claims in this repository are tied to executable tests, artifacts, portal records, or explicitly marked limitations.
